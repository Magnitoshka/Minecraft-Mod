# Changelog

## 0.7.0+26.3 — 2026-10-30

Persistent building upgrades and town-hall progression with prerequisites and settlement unlocks. Added all specified building kinds with three template tiers, server-configured immutable contract prices, level-based beds/workplaces/storage/speed/tools and mine tables. Preserved legacy houses, paid jobs and unchanged containers. High configured material prices are delivered through multiple trips into persisted per-step staging. Map development page, upgrade buttons, authoritative prices and RU/EN text; protocol7. Fixed-size fields and later-stage professions/combat/trade remain future work.

## 0.6.0+26.3 — 2026-10-30

Exclusive persistent builder assignments and four-slot material trips, owner conversations that stop residents, traffic yielding, local-height sites with sloped access preserving existing roads, a paginated resident roster, physical lumber-hut barrels with a one-time gift of10 oak saplings, real wood/sapling collection and warehouse couriers. Production cargo stays carried on profession changes; departures leave physical items rather than bypassing storage capacity. Static review, Java25 clean assemble and SHA256 verification passed. Final delivery uses the Gradle-built JAR; earlier cached fallback packaging was superseded. No game/server/test runtime.

## 0.3.0+26.3 — 2026-10-30

Fixed SDL map placement input and visible action feedback; added loaded-only terrain/height survey and placement hints, per-blueprint resource icons, live overhead builder activity, a native warehouse menu with player inventory and multi-stack deposits, and post-result notifications. Fixed numeric NBT boolean loading, repeat starter banners and persisted territory radii; removed generated hall roof banners. Completed the player-feedback queue through static review and compilation only. Installed/applied ub-mode for the final code edit; optional quality tools were absent and skipped per user instruction.

## 0.2.0+26.3 — 2026-10-30

Playable first-level construction and resource loop: houses, warehouses, lumber huts, mines and wheat fields; builder/lumberjack/miner/farmer jobs; XP, work status, real beds and growing warehouse capacity. Medieval parchment map with native timber buttons and building previews. Deterministic personal citizen skins generated locally. Owner-attributed damage is blocked. OP-only `/settlementadmin` edits wallets, treasury, food and residents. Protected edits, bounded path calculations and skin cleanup are included. Compiled without stand/runtime tests at the author's request.

## 0.1.0+26.3 — 2026-10-29

First stage MVP for Forge 66.1.0 / Minecraft 26.3 / Java 25. Includes founder banner and starter kit, safe camp placement and instant hall, custom citizens, world SavedData, ownership checks, virtual storage, wallets and treasury transfers, recruitment, daily nutrition/starvation/immigration, beds and sleep, bilingual map UI on M, and configurable stage-one balance. Construction/production/combat/trade/AI settlements are future stages.
