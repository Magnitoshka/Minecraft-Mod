# Умные поселения — MVP 0.1.0

Мод для **Minecraft Java 26.3, Minecraft Forge 66.1.0, Java 25**. Это первый игровой этап спецификации, а не все восемь этапов.

[Скачать готовый JAR](artifacts/smart-settlements-0.1.0%2B26.3.jar) · [SHA-256](artifacts/SHA256SUMS)

## Установка и первый запуск

1. Установите Forge **26.3-66.1.0** в лаунчере.
2. Поместите `smart-settlements-0.1.0+26.3.jar` в папку `mods`. На выделенном сервере установите тот же JAR и на сервер, и на клиенты.
3. Создайте тестовый мир. При первом входе выдаются знамя основателя, каменные инструменты, 16 хлеба и 50 монет.
4. Подготовьте ровную площадку **9×7** на твёрдом основании, с шестью свободными блоками по высоте. Нажмите ПКМ знаменем по земле около центра площадки.
5. Появится главное здание с тремя кроватями, бочкой склада и верстаком управления, а также три собственных поселенца мода.
6. Нажмите **M**. Клавиша переназначается в управлении. Карта перемещается перетаскиванием, масштабируется колесом и кнопками `+`/`−`.

## Что можно проверить

- На карте видны граница лагеря, здание, жители и позиция игрока. Справа отображаются население/кровати, казна, кошелёк, склад и запас еды.
- В небольшом окне прокручивайте **правую панель** вниз до действий с монетами и найма. Укажите сумму и переведите монеты в казну или обратно. Переименуйте поселение.
- Вкладка **Жители** или ПКМ по жителю открывает карточку. Доступны «строитель» и «без профессии»; рабочий ИИ строительства относится ко второму этапу.
- Подойдите к центру здания на расстояние до **8 блоков**. Во вкладке **Склад** нажмите «Положить из руки», чтобы сдать обычный стак ресурсов. Кнопка ресурса забирает до **16 штук**. Если инвентарь заполнен, предметы выпадают рядом с игроком. Предметы с изменёнными компонентами, прочностью или содержимым контейнеров не принимаются в числовой склад.
- Бочка и верстак в главном здании также открывают управление. Виртуальные ресурсы не находятся в физической бочке.
- Стартовый склад: 64 дубовых бревна, 64 булыжника, 48 хлеба. Вместимость 1000 единиц. Еда сохраняет свой тип; учитывается питательность (один хлеб — одна дневная порция).
- Ночью жители идут к закреплённым кроватям. При разрушении кровати настроение падает.
- Чтобы проверить голод, заберите всю еду со склада и пропустите три дня. В первый день скорость работы уменьшается, во второй работа останавливается, на третий жители уходят. В этом этапе рабочие задания ещё не реализованы, поэтому коэффициент скорости виден в модели и покрыт тестами.
- Наём стоит 30 монет и требует свободную кровать. В стартовом лагере все три места заняты: сначала освободите место (например, дождитесь ухода голодного жителя). Переселенец может появиться раз в день при свободном месте, достаточной еде и хорошем настроении.
- Другой лагерь можно основать не ближе **160 блоков между центрами** при стандартном конфиге. Новое знамя покупается у главного здания из казны: 200 монет, далее ×1.5. Источники дохода относятся к последующим этапам; для тестирования покупки можно увеличить стартовый кошелёк в конфиге.
- После сохранения и повторного входа проверьте название, монеты, ресурсы, профессии и тех же жителей. Стартовый набор повторно не выдаётся.
- На сервере только владелец может управлять данными своего поселения. Другая размерность считается отдельной территорией.

## Настройки

Файл мира: `<world>/serverconfig/smartsettlements-server.toml`. Баланс этапа 1 вынесен в настройки. Загрузка поселений ограничена восемью на владельца; временные билеты чанков не изменяют ручной список `/forceload`.

## Что будет в следующих этапах

Постройка и улучшение зданий строителями, добыча, поля, армия, ИИ-поселения, торговля, дороги, рейды и квесты **пока не реализованы**. Стартовое главное здание пока требует расчищенной площадки; автоматическое выравнивание относится к этапу 2. Жители используют временную внешность Steve из ванильных ресурсов.

## Сборка и проверки

```bash
# Нужна Java 25. Gradle загружается wrapper-скриптом.
./gradlew build
./gradlew runGameTestServer
./gradlew runClient
```

Готовый мод: `build/libs/smart-settlements-0.1.0+26.3.jar`.

17 модульных тестов проверяют размещение, склад, голод, питание, найм, владение, переполнение чисел и сериализацию. Три GameTest работают в настоящем сервере Forge и проверяют регистрацию/тики сущности, экономику/питание и состав главного здания. Отчёт GameTest: `build/gametest-results.xml`. Тестовые определения исключены из распространяемого JAR.
